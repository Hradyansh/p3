🌌 Mindscape 3D v2

A walkable 3D space where every object opens into a real workspace — documents, spreadsheets, slides, whiteboards, lists, a private journal and photo/video galleries. Everything autosaves in this browser (IndexedDB). Use File → Export for backups.

1 · PlacePick a piece in Build — the Workspaces group has Docs, Sheets, Slides, Whiteboards, Lists, Journal, Gallery and Screens.
2 · OpenDouble‑click an object (or select it and press Enter). It expands into a window with pages — float it, dock it beside the 3D world, or go full screen.
3 · GrowPress X to grow an object big in the space so its live screen is readable from afar; =/- resize it.

Inside the editors

Docs: type / for blocks, Markdown shortcuts (#, -, 1., >, []), Ctrl+F find & replace. Sheets: formulas like =SUM(A1:A9), =IF(), =SUMIF(), charts, CSV. Whiteboard/Slides: V select, R rect, O ellipse, D diamond, T text, S sticky, C connector, P pen, F frame, Space+drag pan, Ctrl+wheel zoom. Lists: Enter new item, Tab indent, → open, Space done.
